# Article Pack — 一站式文章处理

用户输入一篇文章，自动判断文章类型，并行完成 5 项处理任务。

## 文章类型判断

读取文章后，自动判断类型，决定配图和封面的视觉风格：

| 文章类型 | 判断依据 | 配图风格 | 封面风格 |
|---------|---------|---------|---------|
| **教程类** | 含步骤说明、代码块、软件/工具名称、GitHub 项目链接 | `infographic`（清晰、写实感、截图风） | cinematic + clean tech（简洁科技感） |
| **观点类** | 议论、思考、行业评论、个人感悟 | `scene`（温暖插画风） | cinematic + warm（温暖电影感） |

判断结果写入变量 `{article_type}` 和 `{illust_style}`，传递给各 Agent。

流程图：
```
你发文章
    │
    ├─ 判断类型 → tutorial / opinion
    │
    ├─ ① 配图     →  baoyu-article-illustrator（风格随类型切换）
    ├─ ② 封面     →  article-cover-16x9（风格随类型切换）
    ├─ ③ 撰写标题  →  生成 3 个爆款风格标题（回显到对话）
    ├─ ④ 转即刻/X →  x-post（即刻版 + X版，回显到对话）
    └─ ⑤ 生成PPT  →  beautiful-slides（HTML 幻灯片）
```

所有步骤并行执行，完成后统一汇总。

## 输入

支持以下输入形式：
- 文件路径：`.md` / `.txt` / `.docx` / `.pdf`
- 或直接粘贴文章正文

## 执行流程

### Step1：读取文章内容 + 判断类型

一次性读取完整内容，**将全文内容内联到每个子 Agent 的 prompt 中**（不依赖文件路径）。

提取关键信息：
- 文章原标题
- 完整正文
- 是否含代码块 / 步骤说明 / 工具名称 → 判定为 **tutorial**
- 是否以议论/感悟为主 → 判定为 **opinion**
- 核心观点（用于封面和 PPT）

将判定结果写入 prompt 变量：
```
{{ARTICLE_TYPE}} = tutorial 或 opinion
{{ILLUST_STYLE}} = infographic 或 scene
{{COVER_MOOD}} = clean-tech 或 warm-cinematic
```

### Step2：并行派发 5 个子 Agent

**在同一轮回复中用 Agent 工具同时派发 5 个子 Agent**，`run_in_background: true`，真正并行。

每个 Agent 的 prompt 中**直接内联文章全文 + 文章类型判定结果**，不传文件路径（避免读写冲突）。

---

**Agent A — 正文配图**

```
你是 baoyu-article-illustrator 技能的执行者。

以下是完整文章内容（直接使用，不要读文件）：
---
[文章内容全文]
---

文章类型判定：{{ARTICLE_TYPE}}
配图风格要求：{{ILLUST_STYLE}}

执行配图完整流程：
1. 根据文章类型调整配图风格：
   - 如果是 tutorial：type=infographic，风格清晰写实，适合步骤说明
   - 如果是 opinion：type=scene，风格温暖插画，适合情感叙事
2. 分析文章结构，生成 outline（配图位置、目的、视觉内容）
3. 为每张配图生成 prompt，保存到 prompts/ 目录
4. 调用 gpt_image2_gen.py 生成图片（并行）
5. 将图片引用插入文章对应位置
6. 调用 PicGo Server 上传图片，替换本地路径为在线 URL
7. 返回：配图数量、在线 URL 列表、修改后的文章路径
```

---

**Agent B — 封面生成**

```
你是 article-cover-16x9 技能的执行者。

以下是完整文章内容（直接使用，不要读文件）：
---
[文章内容全文]
---

文章类型判定：{{ARTICLE_TYPE}}
封面情绪要求：{{COVER_MOOD}}

执行封面完整流程：
1. 提炼主标题（≤10汉字）和副标题（≤18汉字）
2. 根据文章类型调整封面风格：
   - 如果是 tutorial：干净科技感，蓝色/灰色系，强调工具和方法
   - 如果是 opinion：温暖电影感，橙金/暖棕系，强调情感和思考
3. 构造封面 prompt（含 Text Rendering 字段，要求 AI 渲染主副标题进图）
4. 保存 prompt 到 D:\data\images\Article-illustrations\cover-{slug}-{timestamp}.prompt.md
5. 调用 gpt_image2_gen.py 生成封面图
6. 返回：封面图路径 + prompt 文件路径
```

---

**Agent C — 撰写标题**

```
你是爆款标题专家，熟悉咪蒙标题方法论和公众号爆款逻辑。

以下是完整文章内容（直接使用，不要读文件）：
---
[文章内容全文]
---

任务：基于文章原标题，生成 3 个爆款风格标题。

要求：
1. 每个标题 ≤20 汉字
2. 3 个标题风格各不相同，例如：
   - 悬念式：用提问或反常结论制造好奇
   - 数字式：用具体数字增强可信度
   - 情绪式：用强烈情绪词触发共鸣
3. 每个标题后附 1 句简短说明（为什么这个标题会爆）
4. 直接返回 3 个标题 + 说明，不要问用户选择，全部输出

返回格式：
**标题1（悬念式）：** [标题内容]
> [说明]

**标题2（数字式）：** [标题内容]
> [说明]

**标题3（情绪式）：** [标题内容]
> [说明]
```

---

**Agent D — 社交媒体改写**

```
你是 x-post 技能的执行者。

以下是完整文章内容（直接使用，不要读文件）：
---
[文章内容全文]
---

执行社交媒体改写，结果直接返回文字内容（不保存文件）：

1. 即刻版：≤140 字，适合即刻平台风格，有标题、正文、相关话题标签
2. X/推特版：≤280 字符，适合 X/Twitter 平台风格，有标题、正文、相关话题标签
3. 两个版本直接返回文字，不要保存到文件
4. 返回：即刻版文案 + X版文案（纯文字，回显到对话）
```

---

**Agent E — PPT 生成**

```
你是 beautiful-slides 技能的执行者。

以下是完整文章内容（直接使用，不要读文件）：
---
[文章内容全文]
---

执行 PPT 生成流程：
1. 根据文章内容设计幻灯片结构（封面页 + 内容页 + 结尾页）
2. 使用 beautiful-html-templates 设计风格
3. 生成单文件 HTML，保存到文章同目录，文件名：{文章标题}-slides.html
4. 返回：PPT 文件路径
```

  - ...

- `[封面路径]`

> [说明]

**标题3（情绪式）：** [标题内容]

[内容]

## 重要约束

- **5 个 Agent 必须在同一次回复中派发**，`run_in_background: true`
- 子 Agent 的 prompt 中**内联文章全文 + 文章类型判定结果**，禁止使用文件路径（防止读写冲突）
- 某个 Agent 失败不影响其他 Agent
- **③撰写标题和④社交媒体的结果必须回显到对话**，不保存文件、不追加到文章
- 如果用户输入中已经明确说了「不用确认」「直接处理」，跳过任何确认步骤，直接派发 Agent
