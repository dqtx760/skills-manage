# 引流软文写作技能

## 核心写作框架

按照以下黄金比例结构写作，严格遵守篇幅分配：

| 层级 | 占比 | 主要功能 |
|------|------|----------|
| **引入部分** | ~15% | 制造悬念、描述问题现象、建立读者共鸣 |
| **原因分析** | ~25% | 解释背后逻辑、分析深层动机、建立权威感 |
| **解决方案** | ~50% | 提供具体操作步骤、图文并茂、层层递进 |
| **结尾/更新** | ~10% | 总结、补充最新方法、引导互动 |

---

## 各部分写作规范

### 一、引入部分（15%）

**写作目标**：抓住读者注意力，建立共情，让他们觉得"这说的就是我"

**必须包含**：
1. **悬念式开头**：用"突发！"、"居然！"、"我懵了！"等情绪化词汇制造冲击力
2. **个人体验**：用第一人称描述自己遇到的问题（"我最近也中招了"）
3. **共情铺垫**：指出"很多人都遇到了"、"不少人中招了"，建立群体共鸣
4. **配图占位符**：至少 2 张截图占位符，展示问题现象

**句式参考**：
```
突发！[产品/功能] 居然 [问题]，我一脸懵逼...
就在最近，在使用 [产品] 的时候，突然告诉我需要 [验证/付费/其他]。
然后我一脸蒙蔽，后续去搜了一下才发现，确实有不少人中招了...
```

---

### 二、原因分析（25%）

**写作目标**：解释清楚"为什么会这样"，展现专业深度，建立信任感

**必须包含**：
1. **核心发现**：揭示问题的本质特征（"不是所有人都中招，是选择性的"）
2. **具体表现**：描述问题出现的具体场景、触发条件
3. **高危人群/特征**：列出 3 类最容易遇到问题的账号/人群类型
4. **深层原因剖析**：用一级标题突出真正的原因（"一、真正的原因：XXX"）
5. **官方行为逻辑**：分析平台方背后的策略和动机
6. **关键细节**：补充 1-2 个大多数文章没提到的细节，体现独家性

**写作技巧**：
- 多用"根据社区大量用户实测反馈"、"很多人可能还不知道"等表述
- 引用行业变动、数据来支撑观点
- 配图占位符：1-2 张分析类图片

---

### 三、解决方案（50%）**核心部分，篇幅最大

**写作目标**：提供阶梯式解决方案，从简单到复杂，从免费到付费

**必须包含**：

1. **方案阶梯结构**：
   - 方案 1：最简单但效果不稳定的临时方法
   - 方案 2：主流解决方案（接码/工具/操作步骤），配详细图文
   - **→ 在此处自然植入引流文案**
   - 方案 3：失效方法说明（证明你懂行，增加可信度）
   - 方案 N：终极推荐方案

2. **操作步骤要求**：
   - 每步配一张配图占位符 `![操作说明](图片URL)`
   - 明确说明成功率、风险、成本
   - 用"亲测有效"、"实测"、"社区反馈"等词汇增强可信度

3. **引流文案植入规范**：

**植入位置**：在主流解决方案介绍完之后，读者遇到困难、觉得麻烦的那个节点

**标准模板（直接使用，可根据主题微调关键词）：
```
觉得麻烦不想折腾的同学可以移步公众号：**[你的公众号名称]** 后台回复 **[关键词]** 获取大神收藏的最新 [资源/渠道/工具]。
```

**植入原则**：
- ✅ 顺其自然：前面先讲清楚痛点、讲清楚自己折腾的成本和风险
- ✅ 提供价值：公众号提供的是"更优解"、"懒人方案"、"内部资源"
- ❌ 不要硬广：不要一上来就推公众号
- ❌ 不要欺骗：明确说明"这是省事的替代方案"

---

### 四、结尾/更新（10%）

**写作目标**：总结全文，提供最新补充，引导互动

**必须包含**：
1. **终极推荐方案**：单独成小节，标"推荐"、"最省事"标签
   ```
   ### 升级 Plus（推荐，最最省事）
   ```
2. **兜底说明**：如果方案仍不工作，给出替代排查方向（如"99% 是 IP 问题"）
3. **实用工具推荐**：1-2 个辅助检测工具
4. **互动引导**："有问题欢迎留言"、"后面有更多方法会继续更新"
5. **编辑信息**：标注编辑时间和地点，增强时效性

---

## 配图规范

全文配图数量：**8-15 张**，分布如下：
- 引入部分：2-3 张（问题截图）
- 原因分析：1-2 张（分析图、数据图）
- 解决方案：5-8 张（操作步骤截图，每步一张）
- 结尾部分：1-2 张（结果展示图）

**配图占位符格式**：
```markdown
![描述性文字](https://placeholder-image-url.jpg)
```

---

## 语言风格要求

1. **口语化**：像朋友聊天一样，不用书面语
2. **情绪化**：用"薅疯了"、"骂声一片"、"翻车了"等有情绪的词汇
3. **确定性**："今天一次性说清楚"、"原因只有一个"
4. **亲测感**："我自己多次实测有效"、"亲测前期还 OK"
5. **社区感**："社区里大量用户反馈"、"Reddit 和 Telegram 群里当时骂声一片"

---

## 写作流程

当用户提供写作任务时：

1. **先问清需求**（如果信息不足）：
   - 文章主题是什么？
   - 目标读者是谁？
   - 引流的公众号名称是什么？
   - 回复关键词是什么？
   - 引流提供的资源/价值是什么？

2. **按照四部分结构写作**，严格遵守篇幅比例
3. **在解决方案中段自然植入引流文案**
4. **每部分都加配图占位符**
5. **输出完整的 Markdown 格式文章**
